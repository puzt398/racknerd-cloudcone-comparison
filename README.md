## 两年下来实际花多少钱

按年付算两年的现金支出：RackNerd 1GB 档 $11.29 × 2 = **$22.58**，CloudCone 1GB 档 $14.99 × 2 = **$29.98**，差 $7.40。只看这个数字，两家几乎没区别。

真正拉开距离的是退款规则。**RackNerd 不提供退款**，机器开通即计费，买错机房、买错配置，损失是整年的钱。**CloudCone 支持 7 天内按小时计费扣除已用时长，剩余金额退回账户余额**，超过 7 天不再受理。第一次买、还没想清楚要哪个机房的人，这条规则比三五美元的差价重要得多。余额只能留在账户里继续消费，不等于原路退回银行卡，这一点要提前明白。

续费是另一头。RackNerd 的促销套餐历来按同价续费，购买前仍要看清该套餐页面的续费说明，官方并没有把所有套餐的续费价写成一个统一承诺。CloudCone 把“终身锁价”写进了政策，第三方汇总页在 2026 年 9 月读取时标注其续费价为“未公布”，两种说法并存，下单页的结算金额才是准的。

## 几个下单后才知道的收费点

**流量翻倍要自己去论坛申请。** 买完促销套餐，到 LowEndTalk 的 RackNerd 官方活动帖下留言并附上订单号，首次申请免费把月流量翻倍，1GB 套餐从 2TB 变 4TB，续费后仍是翻倍后的额度。流程需要先注册 LET 账号，审核通常两小时到数小时，留言后约 2 到 3 天生效。不申请就按原流量跑，不会自动到账。

**换 IP 的收费不一样。** RackNerd 首次换 IP 免费，控制面板里自助操作；开机 72 小时之后再换，$3 一次。CloudCone 没有免费额度，每次 $2，或者删掉机器重建碰运气换一个 IP，7 天内删除可以按小时计费退回余额。开机先用 ping.pe 这类工具测一下 IP 在境内是否可达，被墙就趁早换。

**CloudCone 是预存余额模式。** 下单前要先充值，费用从余额里扣，SC2 按小时计费也是同一个逻辑。RackNerd 直接按订单付款，支持支付宝、PayPal、信用卡，另有加密货币和银行转账。

**两家都收支付宝，售后语言不一样。** RackNerd 有华人参与运营，中文工单实际响应在 5 到 15 分钟，官方口径是工单平均 10 分钟内回复，用户反馈多在半小时内解决。CloudCone 只有英文支持，响应 30 到 60 分钟，忙的时候要等几个小时。

## 什么情况下该选 CloudCone

有三种需求 RackNerd 满足不了，这时候 CloudCone 更合适：

- **按小时计费的临时机器**。跑几天就关掉的测试、临时编译环境，SC2 按小时扣余额，用完关机不再计费，比年付一台闲置机器划算。
- **控制台自带快照和自动备份**。SC2 内置自动备份、快照、托管防火墙、一键应用和 VNC，RackNerd 标准 VPS 这些都要自己搭。
- **要调 API 做自动化**。CloudCone 面板是自研的，提供 API 接口和较完整的帮助文档；RackNerd 用 WHMCS 加 SolusVM 的现成组合，稳定但扩展性一般。

还有一个流传很广的说法需要澄清：CloudCone 的 VPS 走的是普通国际线路，**CN2 GIA 只出现在它的独立服务器上，价格 $200 以上每月**。早年有帖子说 CloudCone VPS 走 CN2 GIA，那是电信网络调整期间的偶发路由，现在早已恢复。RackNerd 同样是普通国际线路，两家在这个价位都没有优质回国线路可言，冲着 CN2 来的可以直接排除这两家。

性能方面，有第三方测评称 RackNerd 的 Intel VPS 在 CPU 性能上略强于 CloudCone 同档机型，25% 到 35% 这个数字出现在两篇措辞高度相似的转述里，没有公开测试方法，只能当参考，不适合当作选购依据。
